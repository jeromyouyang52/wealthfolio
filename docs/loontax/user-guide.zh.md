# LoonTax 使用说明（测试版）

LoonTax 基于开源的 Wealthfolio，加上了加拿大税务功能：跨账户 ACB、表面亏损
（Superficial
Loss）规则、TFSA/RRSP/FHSA 供款额度、年度资本利得报表。所有数据只存在你
自己的电脑上。

仅供参考，不构成税务或投资建议。报税前请对照你自己的记录核对，一切以 CRA 的规定为准。

## 安装（Windows）

1. 运行 `LoonTax_…_x64-setup.exe`。
2. 测试版没有代码签名，Windows 会弹出"Windows 已保护你的电脑"。点"更多信息"→"仍要运行"。
3. LoonTax 的数据和 Wealthfolio 分开存放，两个可以同时装。

## 第一次使用

1. **建账户**：设置 → 账户，为每个券商账户建一个账户。
2. **标注册类型**：编辑账户时，在"加拿大税务"一栏选 CRA 注册类型（非注册、TFSA、RRSP、
   FHSA 等）和持有人（本人或配偶）。没选的账户不进入税务计算。
3. **导入交易**：活动 → 导入，选账户，再选文件。
   - Questrade：网页版 Activities → Export，存成 CSV（"Export to
     Excel" 给的是 .xlsx，要先
     另存为 CSV），模板选 Questrade。
   - IBKR：建一个 Flex
     Query，选 Trades 部分、CSV 格式、不要表头和表尾记录，模板选
     Interactive Brokers。
   - 一个 Questrade 文件可能含多个账户，导入时把每个账号对应到 App 里的账户。
4. **看税务报告**：左侧导航"税务"。
   - 资本利得：各年利得、持仓 ACB、卖出记录、被否认的亏损。没算进去的证券会列出原因。
   - 供款额度：点右上角"供款额度"，在每张卡片上填一次 CRA 的起始数字：
     - TFSA：CRA 账户里的"1 月 1 日额度"（或你开始符合资格的年份，得到估算）
     - RRSP：评税通知书上的"可用供款额度"
     - FHSA：开第一个 FHSA 的年份
5. **年度报表**：资本利得视图 → "年度报表"，选年份，"下载 CSV"或"打印或存为 PDF"
   （在打印对话框里选"另存为 PDF"）。

## 需要知道的限制

- 外币按加拿大银行当日汇率折算，第一次打开报告时会联网取汇率（只发送币种和日期）。
- 卖出所得是扣除佣金后的净额。
- 同一只证券如果在 App 里有两条资产记录，页面会提示；请把交易合并到一条记录上。
- 配偶 RRSP 的供款、FHSA 取款、来自其他机构的转账不会硬算，会列在"未计入或按假设
  计入"里。
- 应用内的"检查更新"在测试版里不可用；有新版本时重新安装即可。
- 界面里部分地方仍显示 Wealthfolio 的名字。
